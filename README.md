# 📻 اللاسلكي العائلي (family-talk)

**جهاز لاسلكي صوتي للعائلة يعمل داخل شبكة المنزل فقط** — بلا إنترنت، بلا حسابات، بلا متاجر تطبيقات، وبلا تنصيب أي شيء على الجوالات.

> بث مباشر بالضغط للتحدث (WebRTC ندّاً لندّ — الصوت لا يمر بالسيرفر) · رسائل صوتية تُشغَّل تلقائياً بصوت عالٍ مثل الإنتركم · قنوات خاصة بين اثنين · يُثبَّت على الشاشة الرئيسية كأنه تطبيق حقيقي.

## ⚡ التشغيل السريع

المتطلبات: **Node.js ≥ 20** ومعرفة عنوان اللابتوب في الشبكة المحلية.

```bash
git clone https://github.com/afkw2aziz-cmyk/lan-walkie-talkie.git
cd lan-walkie-talkie

npm install                 # الاعتماد الوحيد: ws
bash public/icons/make-icons.sh   # توليد الأيقونات (يحتاج ffmpeg)
bash certs/generate.sh      # توليد شهادة HTTPS محلية

LAN_IP=$(hostname -I | awk '{print $1}')   # عنوان اللابتوب
bash certs/generate.sh       # أعد التوليد إذا تغيّر العنوان
node server.js               # أو: npm start
```

ثم من أي جوال على نفس شبكة الواي فاي:

| ماذا | العنوان |
|---|---|
| التطبيق | `https://<LAN_IP>:8443` |
| صفحة تهيئة الجوالات (شهادة + QR) | `http://<LAN_IP>:8080` |

> `192.168.1.50` مثال فقط — بدّله بعنوان لابتوبك من `hostname -I`.

---

## 1) الحالة الحالية

| العنصر | القيمة |
|---|---|
| **الإصدار** | يُعرَض في شاشة الدخول وفي لوحة الإعدادات ⚙ وفي صفحة التهيئة · ويُعلَن في `/api/health` |
| عنوان التطبيق | `https://<LAN_IP>:8443` (أو `https://<hostname>.local:8443` إن كان mDNS يعمل) |
| صفحة تعريف الجوالات | `http://<LAN_IP>:8080` |
| رمز العائلة | في `data/config.json` · أو `/code` **على جهاز الخدمة نفسه فقط** (`http://127.0.0.1:<8080>/code`) — لا يُعرض لأجهزة الشبكة |
| الخدمة (اختياري) | `systemctl --user status family-talk` |
| استهلاك الذاكرة | ~20 ميجابايت |

---

## 2) تهيئة الجوالات (مرة واحدة لكل جوال)

من الجوال الموجود على نفس شبكة الواي فاي، افتح `http://<LAN_IP>:8080`.

ستظهر صفحة عربية فيها رمز QR وزر تحميل شهادة الثقة، وشرح مصوّر لكل خطوة لأندرويد وللآيفون.

الترتيب: **(١) حمّل الشهادة وثبّتها ← (٢) افتح التطبيق ← (٣) أضفه إلى الشاشة الرئيسية ← (٤) اكتب اسمك ورمز العائلة**.

> **لماذا شهادة؟** المتصفحات لا تسمح باستخدام الميكروفون إلا على اتصال مشفّر (HTTPS).
> الشهادة مصنوعة على جهازك وليست من أي جهة خارجية. ثبّتها على أجهزة العائلة فقط.

## 3) الاستعمال اليومي

| ما تريد | كيف |
|---|---|
| بث مباشر | اضغط مع الاستمرار على الزر الدائري ← اتكلم ← اتركه |
| رسالة صوتية | اضغط 🎙 ← سجّل ← «إرسال». تصل وتُشغَّل تلقائياً عند الآخرين |
| محادثة خاصة | اضغط شريحة «خاص: فلان» أعلى الشاشة |
| كتم السماعة | زر 🔊 على اليسار |
| إعدادات (اهتزاز / تشغيل تلقائي / الاسم) | زر ⚙ |

القناة لا تسمح إلا لمتحدث واحد في الوقت نفسه، ومن يضغط أثناء حديث غيره يرى «فلان يتكلم الآن…» ثم ينتظر.

## 4) الأوامر

```bash
bash tools/family-talk.sh status     # الحالة + فحص الصحة
bash tools/family-talk.sh logs       # آخر السجلّات
bash tools/family-talk.sh code       # رمز العائلة
bash tools/family-talk.sh restart    # إعادة تشغيل يدوية
```

### التشغيل كخدمة مستخدم (systemd)

```bash
systemctl --user restart family-talk          # إعادة تشغيل
systemctl --user disable --now family-talk    # إيقاف التشغيل التلقائي
```

### تغيير رمز العائلة

```bash
nano data/config.json     # عدّل قيمة familyCode
systemctl --user restart family-talk
```

بعدها امسح بيانات الموقع من كل جوال (أو اكتب الرمز الجديد في شاشة الدخول).

### إذا تغيّر عنوان اللابتوب

لتجنّب ذلك: اطلب من الراوتر تثبيت العنوان (DHCP Reservation) للابتوب.
إن تغيّر فعلاً، أعد توليد الشهادة **وثبّتها على الجوالات مرة أخرى**:

```bash
bash certs/generate.sh --force && systemctl --user restart family-talk
```

## 6) كيف يعمل

```
   جوال أ ──────┐                      ┌────── جوال ب
                │  WebSocket (وسيط)     │
                └──── سيرفر اللابتوب ────┘
                        :8443
        ┌──────────────────┴──────────────────┐
   بث مباشر:                              رسائل صوتية:
   WebRTC ندّاً لندّ (الصوت لا              تُرفع للسيرفر ثم
   يمر بالسيرفر إطلاقاً)                    تُبثّ لمن في القناة
```

* الاتصال مشفّر بـ TLS، والدخول محميّ برمز العائلة.
* لا يُرسَل شيء إلى الإنترنت؛ كل شيء داخل الشبكة المحلية.
* الرسائل الصوتية تُحفظ في `data/media` وتُحذف بعد 7 أيام (بحد أقصى 400 رسالة).

## 7) حدود معروفة (اقرأها بصدق)

1. **الآيفون لا يشغّل الميكروفون في الخلفية.** التطبيق يعمل فقط والشاشة مفتوحة عليه.
   لإشعار يوقظ الجوال في الجيب يلزم تطبيق أصلي + حساب مطوّر من آبل (99$/سنة) — خارج نطاق هذا المشروع.
2. **الرسائل الصوتية على الآيفون** تخرج من السماعة الخارجية بصوت عالٍ (موثوقة).
   أما **البث المباشر** فقد يخرج من سماعة الأذن لأن سفاري يوجّه الصوت كـ«مكالمة» عند تشغيل الميكروفون.
3. **عزل الأجهزة (AP Isolation)** في بعض الراوترات يمنع الجوالات من الوصول إلى اللابتوب.
   إن لم يتصل التطبيق: أوقف هذا الخيار من إعدادات الراوتر.
4. **البث المباشر يحتاج تحققاً على أجهزة حقيقية**: الوساطة والمسارات مُختبرة آلياً، لكن بيئة الأتمتة
   لا تستطيع تكوين مرشّحات ICE حقيقية. إن ظهر «البث المباشر يتصل…» ولم يعمل، فالرسائل الصوتية
   تعمل دائماً كبديل مضمون (تمرّ عبر السيرفر).
5. **اللابتوب هو قلب النظام**: إن أُغلق توقف كل شيء.
6. البث المباشر مصمّم لِـ 5–6 أجهزة كحد أقصى (كل جهاز يتصل بالآخر مباشرة).

## 9) الإصدارات

رقم الإصدار له **مصدر واحد فقط**: حقل `version` في `package.json`.

| أين يظهر | كيف |
|---|---|
| شاشة الدخول · لوحة الإعدادات ⚙ · صفحة التهيئة | يحقنه السيرفر في HTML عبر `<meta name="app-version">` |
| `/api/health` | `{"ok":true,"version":"...",...}` |
| شارة أعلى هذه الصفحة | تقرأها shields.io من آخر `git tag` |
| كسر تخزين الواجهة | `styles.css?v=` و`app.js?v=` مربوطان بالرقم تلقائياً |

سجل التغييرات الكامل وقواعد الترقية في [CHANGELOG.md](CHANGELOG.md).
لفحص نسخة الخدمة العاملة من أي جهاز:

```bash
curl -sk https://127.0.0.1:8443/api/health | python3 -m json.tool
```

> لا تكتب رقم الإصدار يدوياً في أي ملف آخر — ارفعه في `package.json` فقط،
> والباقي يتبعه.

## 10) تبديل رمز العائلة

رمز العائلة هو **حدّ الحماية الوحيد**، فلا يعمل التطبيق بغيره. للتبديل:

```bash
systemctl --user stop family-talk
# عدّل familyCode في data/config.json (6 خانات من A-Z و2-9 — بلا I/O)
systemctl --user start family-talk
```

ثم **بلّغ به الجميع** — التطبيق يحفظ الرمز في الجوال (`localStorage`)، فكل جوال
يكتبه مرة واحدة فقط. وعند تبديله: الجوال المتصل الآن يبقى متصلاً، وأي جوال يُعيد
تحميل الصفحة يُرفض حتى يكتب الرمز الجديد.

**قواعد أمنية:** لا تُرسل الرمز في مجموعة عامة، ولا تعرضه على شاشة أمام زائر، ولا
تستخدمه في مكان آخر. صفحة `/code` تُعرض على جهاز الخدمة نفسه فقط — ولهذا من كان
على الشبكة لا يقرؤه.

> لمراقبة من يدخل: `journalctl --user -u family-talk -f` — يُسجَّل كل دخول ناجح
> وكل محاولة فاشلة مع العنوان والوقت.

## 11) صمود الخدمة (أن يبقى يعمل)

اللاسلكي خدمة عائلية: إن سقط، سقط معه اجتماع العائلة. ثلاثة أشياء تحكم ذلك:

**١) الإقلاع بلا دخول** — الوحدة وحدة *مستخدم*، فلا تعمل بعد إعادة تشغيل
الجهاز حتى تدخل بحسابك، إلا إذا فُعِّل `linger`. وهو مفعَّل على جهازك:

```bash
loginctl show-user "$USER" -p Linger     # يجب: Linger=yes
sudo loginctl enable-linger "$USER"      # لتفعيله على جهاز آخر
```

**٢) عنوان ثابت** — جوالات العائلة تحفظ رابط التطبيق، فلو تغيّر عنوان الجهاز
انكسرت أيقوناتها المثبَّتة. الحل: احجز العنوان في الراوتر (DHCP reservation /
«ربط العنوان بالماك»):

| القيمة | عندك |
|---|---|
| العنوان | `192.168.100.51` |
| ماك الواي فاي | `60:f2:62:d5:ab:bf` |
| الراوتر | `http://192.168.100.1` (ابحث في إعدادات LAN عن «Static/DHCP Reservation») |

> لو تغيّر العنوان بلا حجز: رمز QR يُحدَّث تلقائياً (يُعاد توليده عند أول زيارة
> لصفحة التعريف)، فالتسجيل الجديد يعمل — لكن الجوالات المثبَّتة تحتاج إعادة تثبيت.

**٣) الاسم البديل (شبكة أمان)** — يعمل اسم الجهاز بلا تحذير لأن الشهادة تحمله:

```
https://pop-os.local:8443
```
استعمله إن دعم جوالك `mDNS` — وقتها تغيّر العنوان لا يهمّك أصلاً. (مُختبر على
هذا الجهاز: يردّ 200.) لكن لا تجعله الأساسي: بعض الأجهزة القديمة لا تدعم `mDNS`.

**وأمر رابع يُنسى: النوم.** إن نام الجهاز مات اللاسلكي معه. جهازك الآن لا ينام
(صفر أحداث سكون في آخر ٧ أيام)، فلا تفعّل «السكون بعد مدة» في إعدادات الطاقة إلا
وأنت تعلم أن اللاسلكي سيتوقف. وإن أغلقت غطاء الجهاز، توقف.
