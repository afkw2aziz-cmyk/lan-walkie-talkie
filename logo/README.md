# 🎨 هوية «اللاسلكي العائلي» البصرية

الشعار الرسمي للتطبيق — المفهوم **B «الجهاز العصري»**: لاسلكي بأطراف ناعمة وتدرّج أخضر،
هوائي، شاشة موجة صوتية، شبكة سماعة، موجات بثّ، ومؤشّر «مباشر» أحمر.

الألوان مأخوذة **حرفياً** من واجهة التطبيق (`public/styles.css`)، فلا يوجد لون جديد واحد.

| الدور | اللون |
|---|---|
| التدرّج الأساسي | `#27d17c` → `#12a862` |
| الخلفية | `#0b1220` |
| موجات البثّ | `#6ef0ab` |
| «مباشر» | `#ff4d5e` |
| الزر الجانبي | `#0d8a4e` |
| الرمادي (هوائي/شبكة) | `#8fa2c4` |

الخطوط المستعملة في الشعار النصي: **Noto Kufi Arabic** (العربية) و**Noto Sans** (اللاتينية).

## 📦 المحتويات

### `svg/` — الأصول المتجهية (المصدر الحقيقي)
تكبير بلا فقدان، وتعديل بالأدوات المتجهية.

| الملف | الوصف |
|---|---|
| `logo-icon.svg` | الأيقونة الكاملة 512×512 (خلفية + علامة) |
| `logo-icon-maskable.svg` | نسخة **maskable** — الرسم داخل المنطقة الآمنة ٦٢٪ |
| `logo-mark.svg` | العلامة وحدها بلا خلفية |
| `logo-mono-light.svg` | أحادي أبيض — للمقاس على خلفية داكنة |
| `logo-mono-dark.svg` | أحادي داكن — للمقاس على خلفية فاتحة |
| `wordmark-ar.svg` | شعار نصي عربي: العلامة يميناً والنص يساراً |
| `wordmark-en.svg` | شعار نصي إنجليزي: `family-talk` + العربية أسفله |
| `stacked.svg` | تخطيط مكدّس عمودي (للحالات المربّعة) |
| `*-light.svg` | نفس الشعارات بخلفية ونص فاتحين |
| `concept-{a,b,c}.svg` | 📁 **أرشيف** المفاهيم الثلاثة الأولى (للرجوع، ليست للإنتاج) |

### `png/` — صور جاهزة (22 ملفاً)

| المجموعة | الأحجام | الاستعمال |
|---|---|---|
| `logo-icon-*` | 32 · 48 · 64 · 128 · 180 · 192 · 512 · 1024 | أيقونة التطبيق والتثبيت والاختصارات |
| `logo-icon-maskable-*` | 512 · 1024 | أندرويد (الدائرة/المربّع حسب الشركة) |
| `logo-mark-*` | 512 · 1024 | شعار داخل واجهة أو مستند — **بخلفية شفّافة** |
| `logo-mono-light-*` · `logo-mono-dark-*` | 512 · 1024 | طباعة، ختم، نقش أحادي **بخلفية شفّافة** |
| `wordmark-ar-1200x360` · `wordmark-en-1200x360` | 1200×360 | ترويسة، عرض تقديمي، README |
| `stacked-800x880` | 800×880 | بوست، غلاف مربّع، بطاقة |
| `*-light` | نفس الأحجام | للخلفيات الفاتحة |

> الأيقونات **180 و 192 و 512 و maskable-512** هي بالضبط الأحجام التي يحتاجها
> التطبيق في `public/icons/` و`public/manifest.webmanifest`.

### `preview/` — للمعاينة فقط
`kit-preview.png` (ورقة الطقم الكامل) و`concept-*.png` (أرشيف المفاهيم).

## 🔁 إعادة البناء

المتطلبات: `python3` + `pycairo` (متوفّران على هذا الجهاز).

```bash
cd logo
python3 build.py final      # يبني كل الأصول المتجهية والنقطية
```

**أصول النصوص** (wordmark/stacked) تحتاج خطوة إضافية: تُولَّد كـ SVG ثم تُصوَّر في
المتصفح، لأن `pycairo` هنا غير مربوط بـ Pango (حزمة `python3-gi-cairo` ناقصة)،
وتشكيل العربية يحتاج محرّك نصوص حقيقياً.

```bash
# 1) شغّل سيرفراً محلياً على مجلد logo
python3 -m http.server 8800 --bind 127.0.0.1 --directory logo
# 2) افتح logo/render/*.html في المتصفح وصوّر الصفحة كاملة، ثم اقتصّها:
#    wordmark-*  →  1200×360        stacked-*  →  800×880
```

### الملفات التقنية
| الملف | الوظيفة |
|---|---|
| `design.py` | كل الرسم المتجهي: الألوان، الأدوات، العلامة، الشعارات النصية |
| `build.py` | يبني الطقم الكامل + صفحات التصوير + ورقة المعاينة |
| `showcase.py` | يبني ورقة المقارنة بين المفاهيم (أرشيف المرحلة الأولى) |
| `render/` | صفحات HTML وسيطة لتصوير النصوص |
| `.cache/` | ملفات مؤقتة (تُعاد بناؤها تلقائياً) |

## ✅ قواعد الاستعمال

1. **لا تكبّر الأيقونة** — استعمل أحجام `png/` المولَّدة، أو SVG.
2. **المسافة الآمنة** = عرض الهوائي حول الشعار من كل جهة.
3. على خلفية داكنة استعمل `logo-mono-light` أو الشعار الكامل؛ على فاتحة استعمل `*-light`.
4. لا تغيّر زوايا التدرّج ولا تُضف ظلالاً — الأيقونة مصمّمة لتُقصّ (mask) من النظام.
5. الحد الأدنى للعرض ١٦ بكسل للعلامة، و١٢٠ بكسل للشعار النصي العربي.
